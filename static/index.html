💡 New here? What does this tool do? ▾

This tool reads the weather forecast for the next few days and tells you the best time to run solar-powered equipment — a pump, a charger, a battery, or anything that needs sunshine.

  1. Pick a location (or keep the default) and how many days ahead to look.
  2. Click "Decide" — we fetch the forecast and run a small machine-learning model.
  3. Read the big answer at the top: run now, wait for a better hour, or skip.

Quick glossary:

☀️GHI (W/m²)
Global Horizontal Irradiance — a measure of how strong the sunlight is, in Watts per square metre. ~0 = night or heavy cloud. ~1000 = full direct sun. Higher is better.
🌧️Rain chance
The probability of rain in that hour, as a percentage (0–100%).
⚡Utility score (0–1)
A single number for how worthwhile that hour is. Closer to 1 = better. Above the GOOD line is ideal; between FLOOR and GOOD is usable; below FLOOR is not worth running.
🎯Verdict
GOOD bright sun · MARGINAL usable but not great · NO too cloudy or dark.
📶Confidence
How sure the model is about its verdict. High = very sure · Medium = fairly sure · Low = a toss-up.

How it works: we pull the hourly weather forecast from Open-Meteo, then a small logistic-regression model predicts three probabilities for each hour — GOOD, MARGINAL, NO. Those combine into a utility score (0–1). The tool then compares three options — run now, wait for a future hour, or skip — and picks whichever scores highest.

This is a simple forecast-based awareness tool. It is not a measurement, savings guarantee, or engineering advice.
